# Start here

Welcome to the [File Bundles](https://github.com/mnaoumov/obsidian-file-bundles/) demo vault. An HTML page and the assets it loads, a note and the images pasted into it, a scanned invoice and the note describing it — these are one thing to you and several files to Obsidian. Move the main file and the rest stay behind; delete it and they are orphaned. This plugin lets a file declare which files and folders belong with it, and then treats them as one **bundle**.

**Your first success:** look at `Materials/01 Bundles/` in the File Explorer. There are two bundles in there — a note with an asset folder, and an HTML file with a stylesheet, an image folder and the sidecar note that declares them. Open `Materials/01 Bundles/Trip note.md` and switch to source mode to see the `file-bundles` key in its frontmatter. That key is the whole declaration.

Then open [01 Bundles](<./01 Bundles.md>). Notes in this vault carry **code buttons**: a captioned rectangle you click to run the TypeScript behind it. The result appears underneath, and the `</>` toggle beside the caption reveals the source. If a button does nothing, the plugin is probably not enabled yet.
